# Salita Quest 5.5.0 — Avatar Collection

This release replaces random weekly avatar rewards with learner-directed account progression.

- New learners choose one of four Philippine flora starter avatars.
- The account-wide collection contains 48 avatars.
- Six Daily Keys provide a choice: unlock a common avatar, add 50 uncommon shards, or add 25 rare-animal shards.
- Levels 10–90 award common or uncommon milestone avatars; Level 99 awards the Golden Salita Crest.
- Locked avatars remain visible in grey, while partially collected avatars progressively reveal their colour.
- Learners can equip any unlocked avatar and use it across Tagalog, Bisaya and achievement sharing.
- New unlocks receive a collection animation with a reduced-motion alternative.
- Existing profile avatars and legacy weekly rewards are migrated without changing learning progress.

Full implementation and acceptance details are in `docs/AVATAR_PROGRESSION_PATCH.md`.
