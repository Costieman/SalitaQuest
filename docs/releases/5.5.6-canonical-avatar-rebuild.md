# Salita Quest 5.5.6 — Canonical Avatar Rebuild

This release replaces the mixed PNG, WebP, SVG-wrapper, sprite-crop, canvas-rewrite and document-observer artwork paths with one governed avatar model and 48 standalone canonical PNG assets.

The build is deterministic: source artwork is converted once during development, validated as 48 unique 128×128 PNGs, and committed. The live app performs no canvas cropping, sprite extraction, catalogue patching or global image observation.

Learner ownership, shard progress, equipped avatar IDs, milestone claims and acknowledgements remain unchanged.
